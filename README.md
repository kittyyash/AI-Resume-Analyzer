## 📌 Overview

**AI Resume Analyzer** is a Python and Streamlit-based web application designed to help users analyze their resumes and compare them against specific job descriptions.

The application extracts information from resumes, identifies important skills and sections, calculates a rule-based resume score, compares resume content with job requirements, and provides improvement suggestions.

> ⚠️ **Important:** The scores generated by this application are automated estimates based on the implemented rules and NLP techniques. They are not official ATS scores, recruiter decisions, or guarantees of employment.

## 📊 Scoring Methodology

The application uses two major approaches for analysis:

### 1. 📋 ATS Resume Score

The ATS score is a **rule-based resume readiness estimate**.

It considers factors such as:

| Factor         | Considered |
| -------------- | ---------- |
| Resume text    | ✅          |
| Skills         | ✅          |
| Education      | ✅          |
| Experience     | ✅          |
| Projects       | ✅          |
| Certifications | ✅          |

> ⚠️ This score is an application-generated estimate and should not be interpreted as an official ATS platform score.

### 2. 🎯 Job Match Score

The application combines:

* 🔑 **Keyword Skill Matching — 60%**
* 🧠 **NLP Relevance — 40%**

Conceptually:

```text
Overall Job Match Score
        =
(Keyword Match × 0.60)
        +
(NLP Relevance × 0.40)
```

## 🧠 NLP Analysis

The application uses **TF-IDF** and **Cosine Similarity** to compare the textual content of a resume with a job description.

```text
Resume Text
     +
Job Description
     │
     ▼
TF-IDF Vectorization
     │
     ▼
Numerical Text Representation
     │
     ▼
Cosine Similarity
     │
     ▼
NLP Relevance Score
```

TF-IDF represents the importance of terms within the text, while cosine similarity measures the similarity between the resulting text representations.

## 🚀 Getting Started

### 📋 Prerequisites

Make sure you have:

* 🐍 Python 3.x
* 💻 VS Code or another code editor
* 🔀 Git

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/sandhiyabalasubramani/AI-Resume-Analyzer.git
cd AI-Resume-Analyzer
```

### 2️⃣ Create a Virtual Environment

```bash
python -m venv venv
```

### 3️⃣ Activate the Virtual Environment

**Windows:**

```bash
venv\Scripts\activate
```

**macOS / Linux:**

```bash
source venv/bin/activate
```

### 4️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

### 5️⃣ Run the Application

```bash
streamlit run app.py
```

The application will start locally and provide a URL in the terminal.
